# Reely RS-610WP MG 舵机校准指南

## 📐 为什么需要校准？

每个舵机都有个体差异，导致实际转动角度与理论角度不完全一致：

| 问题 | 原因 | 表现 |
|-----|-----|------|
| **零点偏移** | 舵机内部电位器偏差 | 1500μs 时不是正中位置 |
| **行程不对称** | 机械限位不对称 | 左转和右转的最大角度不一样 |
| **脉宽范围偏差** | 舵机控制电路差异 | 实际有效脉宽范围不是 1000-2000μs |
| **舵机臂安装角度** | 安装时角度不对 | 整体偏移一个固定角度 |

---

## 🔍 第 1 步：测量实际角度

### 1.1 准备工作

1. **标记参考线**：
   - 在舵机底座上用记号笔画一条径向线（作为 0° 基准）
   - 在舵机臂上也画一条线
   - 准备量角器

2. **设置中位**：
   ```c
   // 在串口监视器中观察
   [0002] Angle=   0.0deg -> Pulse=1500us (Center, hold 2s)
   ```
   此时舵机应该在中位，记录舵机臂实际角度。

### 1.2 测量方法

运行全范围扫描测试，记录关键点：

| 理论值 | PWM 脉宽 | 实际测量角度 | 偏差 |
|-------|---------|------------|------|
| -90°  | 1000μs  | _______°   | ____ |
| -45°  | 1250μs  | _______°   | ____ |
| 0°    | 1500μs  | _______°   | ____ |
| +45°  | 1750μs  | _______°   | ____ |
| +90°  | 2000μs  | _______°   | ____ |

**测量技巧**：
- 等舵机停稳后再测量（每个位置停留 2 秒）
- 从舵机底座参考线到舵机臂参考线的夹角
- 多次测量取平均值

## 🔧 第 2 步：校准零点（最简单）

如果只是中位偏移，最简单的方法是**调整舵机臂安装角度**。

### 方法 A：重新安装舵机臂（推荐）

1. **设置舵机到中位**：
   ```c
   // 确保代码发送 1500μs
   __HAL_TIM_SET_COMPARE(&htim1, TIM_CHANNEL_4, 1500);
   ```

2. **拆下舵机臂**：
   - 拧下中心螺丝
   - 取下舵机臂（舵盘）

3. **重新安装**：
   - 确保车辆转向机构在**正中位置**
   - 将舵机臂重新安装到最接近正中的齿位
   - 如果有微小偏差（< 5°），可以接受

4. **微调**：
   - 如果还有偏差，修改代码中的 `SERVO_PULSE_CENTER` 宏

### 方法 B：修改中位脉宽（代码校准）

如果不想拆舵机臂，可以修改代码：

```c
// 在 servo.h 中修改
// 原始值：
#define SERVO_PULSE_CENTER      1500

// 校准后的值（根据实际测量调整）：
// 例如：如果 1500μs 时实际偏左 10°，可以尝试：
#define SERVO_PULSE_CENTER      1550   // 增加 50μs（约 9°）

// 或者偏右 10°：
#define SERVO_PULSE_CENTER      1450   // 减少 50μs（约 9°）
```

**计算公式**：
```
偏差角度 → 脉宽调整量
1° ≈ 5.5μs

例如：实际中位偏左 8°
需要增加脉宽 = 8° × 5.5μs/° ≈ 44μs
新中位 = 1500 + 44 = 1544μs
```

## 📏 第 3 步：校准行程范围

如果左转和右转的最大角度不对称，需要调整脉宽范围。

### 3.1 测量实际有效范围

运行全范围扫描，观察舵机：

1. **找到实际最小脉宽**：
   - 从 1000μs 开始增加
   - 当舵机刚开始转动时的脉宽 = 实际最小值
   - 例如：可能是 1050μs

2. **找到实际最大脉宽**：
   - 从 2000μs 开始减少
   - 当舵机停止转动前的脉宽 = 实际最大值
   - 例如：可能是 1950μs

3. **记录机械限位**：
   - 如果舵机发出卡卡声，说明到达机械限位
   - 此时的脉宽就是安全上限

### 3.2 修改脉宽范围

```c
// 在 servo.h 中修改

// 原始值（标准舵机）：
#define SERVO_PULSE_MIN         1000
#define SERVO_PULSE_MAX         2000

// 校准后的值（根据实际测量）：
// 例如：如果实际有效范围是 1050μs ~ 1950μs
#define SERVO_PULSE_MIN         1050
#define SERVO_PULSE_MAX         1950

// 安全限位也要相应调整：
#define SERVO_PULSE_SAFE_MIN    950   // 比 MIN 小 100μs
#define SERVO_PULSE_SAFE_MAX    2050  // 比 MAX 大 100μs
```

## 🎯 第 4 步：非线性校准（高级）

如果发现角度响应不是完全线性的，可以使用查找表校准。

### 4.1 建立校准表

测量多个点的实际角度：

```c
// 在 servo.c 中添加校准表
typedef struct {
    float target_angle;   // 目标角度
    uint16_t pulse_us;    // 对应的实际脉宽
} ServoCalibPoint;

static const ServoCalibPoint calib_table[] = {
    {-90.0f, 1000},  // 根据实际测量调整
    {-45.0f, 1250},
    {  0.0f, 1500},
    {+45.0f, 1750},
    {+90.0f, 2000}
};
```

### 4.2 使用线性插值

```c
static uint16_t Servo_AngleToPulse_Calibrated(float angle_deg)
{
    // 查找目标角度在哪两个校准点之间
    for (int i = 0; i < 4; i++) {
        if (angle_deg >= calib_table[i].target_angle &&
            angle_deg <= calib_table[i+1].target_angle) {

            // 线性插值
            float t = (angle_deg - calib_table[i].target_angle) /
                     (calib_table[i+1].target_angle - calib_table[i].target_angle);

            uint16_t pulse = calib_table[i].pulse_us +
                            (uint16_t)(t * (calib_table[i+1].pulse_us - calib_table[i].pulse_us));

            return pulse;
        }
    }

    // 超出范围，使用线性公式
    return SERVO_PULSE_CENTER + (uint16_t)((angle_deg / 90.0f) * 500.0f);
}
```

## 🚗 第 5 步：车辆转向校准

舵机角度 ≠ 车轮转向角度，需要考虑机械传动比。

### 5.1 测量转向传动比

1. **设置舵机到 -90°**（1000μs）
2. 测量车轮实际转向角度（例如：-30°）
3. **设置舵机到 +90°**（2000μs）
4. 测量车轮实际转向角度（例如：+30°）

### 5.2 计算传动比

```
传动比 = 车轮转角 / 舵机转角
       = 30° / 90° = 0.333

或者反过来：
舵机需要转动的角度 = 车轮目标角度 / 传动比
                   = 车轮目标角度 × 3
```

### 5.3 创建车轮转角控制函数

```c
/**
 * @brief 设置车轮转向角度（考虑传动比）
 * @param htim 定时器句柄
 * @param wheel_angle_deg 车轮目标转角（°）
 * @param data 舵机数据
 */
HAL_StatusTypeDef Servo_SetWheelAngle(TIM_HandleTypeDef *htim,
                                      float wheel_angle_deg,
                                      Servo_Data *data)
{
    // 传动比校准（根据实际测量调整）
    const float gear_ratio = 3.0f;  // 舵机转 3° = 车轮转 1°

    // 计算舵机需要的角度
    float servo_angle = wheel_angle_deg * gear_ratio;

    // 限制舵机角度范围
    if (servo_angle < -90.0f) servo_angle = -90.0f;
    if (servo_angle > +90.0f) servo_angle = +90.0f;

    // 设置舵机角度
    return Servo_SetAngle(htim, servo_angle, data);
}
```

### 测试程序

创建一个简单的验证测试：

```c
void Servo_CalibrationTest(TIM_HandleTypeDef *htim, UART_HandleTypeDef *huart)
{
    Servo_Data servo_data;
    char buffer[100];

    Servo_Init(htim, &servo_data);

    // 测试 5 个关键点
    float test_angles[] = {-90.0f, -45.0f, 0.0f, +45.0f, +90.0f};

    for (int i = 0; i < 5; i++) {
        Servo_SetAngle(htim, test_angles[i], &servo_data);

        snprintf(buffer, sizeof(buffer),
                 "Target: %+6.1fdeg  Pulse: %uus  [请测量实际角度]\r\n",
```

## 🔄 快速校准流程（总结）

### 最简单的 3 步校准：

#### 步骤 1：零点校准（5 分钟）
```c
1. 发送 1500μs 到舵机
2. 观察车轮是否在正中位置
3. 如果偏移，修改 SERVO_PULSE_CENTER 宏
   - 偏左：增加 50-100μs
   - 偏右：减少 50-100μs
```

#### 步骤 2：行程校准（5 分钟）
```c
1. 运行全范围扫描测试
2. 观察舵机是否到达两侧极限
3. 如果卡住或不够，修改 SERVO_PULSE_MIN/MAX
```

#### 步骤 3：验证测试（2 分钟）
```c
1. 测试 -90°、0°、+90° 三个位置
2. 确认车轮转向符合预期
3. 确认无异响、无卡顿
```

## 🛠️ 常见校准问题

### Q1: 1500μs 时车轮不在正中？
**A**: 修改 `SERVO_PULSE_CENTER` 宏，每次调整 20-50μs，重新编译测试。

### Q2: 左转右转不对称？
**A**: 分别调整 `SERVO_PULSE_MIN` 和 `SERVO_PULSE_MAX`。

### Q3: 舵机一直抖动？
**A**: 可能是：
- 机械阻力太大（检查安装）
- 电源电压不稳（检查电源容量）
- 死区设置不当（增加中位死区）

### Q4: 改了代码不生效？
**A**: 确保：
- 重新编译项目（Clean + Build）
- 重新烧录固件
- 复位 STM32
