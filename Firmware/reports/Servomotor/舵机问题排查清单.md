# 舵机不转动问题排查清单

## 🔴 第 1 步：检查串口输出（最重要！）

### 操作步骤：
1. 打开串口监视器（115200 bps, 8N1）
2. 复位 STM32（按复位按钮）
3. 观察串口输出

### ✅ 正常情况应该看到：
```
========================================
  CoVAPSy Servo Motor Test
  Model: Reely RS-610WP MG
========================================

[INFO] Initializing servo...
[OK] Servo initialized! Angle: 0.0deg, Pulse: 1500us

[TEST] Basic function test...
[0001] Angle= -90.0deg -> Pulse=1000us (Left limit, hold 2s)
```

### ❌ 问题诊断：

#### 情况 A：没有任何输出
**原因**：程序没有运行或 UART 连接问题
**解决方法**：
```
1. 检查 UART 连接：
   - STM32 PA2 (TX) → USB转TTL的 RX
   - STM32 GND → USB转TTL的 GND
   - 波特率：115200

2. 检查是否正确烧录：
   - 在 STM32CubeIDE 中点击"Run"（绿色播放按钮）
   - 等待烧录完成（应该显示"Download verified successfully"）

3. 检查 config.h 配置：
   - SERVO_ENABLE = 1
   - SERVO_TEST_ENABLE = 1
   - BNO055_TEST_ENABLE = 0（必须是 0！）
```

#### 情况 B：看到 BNO055 的输出
**原因**：BNO055 测试先运行了（测试程序是互斥的）
**解决方法**：
```
修改 config.h：
#define BNO055_TEST_ENABLE      0    // 改为 0
#define SERVO_TEST_ENABLE       1    // 确保是 1

然后重新编译和烧录
```

#### 情况 C：看到 SHARP 的输出
**原因**：SHARP 测试先运行了
**解决方法**：
```
修改 config.h：
#define SHARP_TEST_ENABLE       0    // 改为 0
#define SERVO_TEST_ENABLE       1    // 确保是 1

然后重新编译和烧录
```

#### 情况 D：看到 Servo 输出但显示初始化失败
```
[INFO] Initializing servo...
[ERROR] Servo initialization failed!
```
**原因**：PWM 启动失败
**解决方法**：→ 跳转到第 4 步检查 TIM1 配置

## 🟡 第 2 步：检查硬件连接

### 2.1 舵机信号线连接（关键！）

**正确连接**：
```
舵机 3 根线：
┌─────────┬──────────┬─────────────┐
│ 舵机引脚 │  颜色    │ 连接到      │
├─────────┼──────────┼─────────────┤
│ 信号     │ 橙色/白色 │ STM32 PA11  │
│ VCC      │ 红色     │ 外部 5V +   │
│ GND      │ 棕色/黑色 │ 外部 5V - 和 STM32 GND │
└─────────┴──────────┴─────────────┘
```

**验证方法**：
1. 用万用表测量舵机 VCC 和 GND 之间电压 = **4.8V ~ 5.2V** ✓
2. 舵机 GND 和 STM32 GND 之间电阻 = **0Ω**（必须共地！）✓
3. 信号线连接到 **PA11 引脚**（不是 PA8！）

### 2.2 引脚确认

**STM32L432KC Nucleo-32 引脚位置**：
```
        D13 (PA5)   D12 (PA6)   D11 (PA7)   D10 (PB6-I2C_SCL)
        D9  (PB7-I2C_SDA)   D8  (PA9)    D7  (PA8-TIM1_CH1)
        D6  (PB1)   D5  (PB0)   D4  (PA3)   D3  (PB4)
        D2  (PB3)   D1  (PA2-TX)   D0  (PA15-RX)

        A7 (PA11-TIM1_CH4) ← 舵机信号线应该连这里！
        A6 (PA10)
        ...
```

**PA11 位置**：在 Arduino 形式的引脚排列中，标记为 **A7**

## 🟣 第 5 步：舵机本身测试

### 5.1 用 Arduino 测试舵机（推荐）

如果您有 Arduino 板，可以先用它测试舵机是否正常：

```cpp
#include <Servo.h>

Servo myservo;

void setup() {
  myservo.attach(9);  // 信号线接 Arduino D9
}

void loop() {
  myservo.write(0);    // 0度
  delay(1000);
  myservo.write(90);   // 90度
  delay(1000);
  myservo.write(180);  // 180度
  delay(1000);
}
```

### 5.2 用示波器/逻辑分析仪（专业方法）

如果有示波器，测量 PA11 引脚：
- 应该看到 **50Hz 的方波**（周期 20ms）
- 脉宽在 **1ms ~ 2ms** 之间变化

## 🛠️ 常见问题速查表

| 现象 | 可能原因 | 解决方法 |
|-----|---------|---------|
| 串口无输出 | 程序未运行 | 重新烧录，检查 config.h |
| 串口显示其他测试 | 测试冲突 | 禁用其他测试的 TEST_ENABLE |
| 初始化失败 | TIM1 配置错误 | 检查 CubeMX 配置 |
| 舵机发热不动 | 信号线连接错误 | 确认连接到 PA11 |
| 舵机抖动 | 电源不足或共地问题 | 检查电源容量和共地 |
| 舵机只转一次就停 | 正常（等待测试延时） | 等待 2 秒后会继续 |
