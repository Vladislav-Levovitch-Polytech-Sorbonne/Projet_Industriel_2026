## 2. 硬件配置

### 2.1 引脚连接
| 传感器引脚 | STM32引脚 | 功能说明 |
|-----------|----------|---------|
| VCC (+)   | 3.3V     | 电源正极 |
| GND (-)   | GND      | 电源地 |
| SCL (C)   | PB6(D5)      | I2C1 时钟线 |
| SDA (D)   | PB7(D4)      | I2C1 数据线 |

**注意**: DFRobot SEN0253 模块已集成 4.7kΩ I2C 上拉电阻，无需外接。

### 2.2 I2C 配置
- **I2C 总线**: I2C1
- **I2C 地址**: 0x28 (7-bit) / 0x50 (8-bit HAL格式)
- **速度**: 400kHz (Fast Mode)
- **通信方式**: HAL_I2C_Mem_Read/Write
- **数据格式**: 小端序 (LSB first)

### 2.3 传感器规格
- **芯片**: Bosch BNO055
- **自由度**: 9-DOF (3轴加速度 + 3轴陀螺仪 + 3轴磁力计)
- **工作模式**: IMU (0x08) - 仅使用加速度计和陀螺仪
- **融合输出**: 四元数、欧拉角、线性加速度、角速度
- **校准系统**: 4级校准 (0=未校准, 3=完全校准)

### 3.2 关键常量定义
```c
// I2C 地址
#define BNO055_ADDRESS          (0x28 << 1)  // HAL 要求左移

// 芯片 ID
#define BNO055_CHIP_ID_VALUE    0xA0

// 工作模式
#define BNO055_MODE_CONFIG      0x00  // 配置模式
#define BNO055_MODE_IMU         0x08  // IMU 模式（目标模式）
#define BNO055_MODE_NDOF        0x0C  // NDOF 模式（未使用）

// 数据转换因子
#define BNO055_QUAT_SCALE       16384.0f  // 四元数: 1 LSB = 1/16384
#define BNO055_EULER_SCALE      16.0f     // 欧拉角: 1 LSB = 1/16 deg
#define BNO055_GYRO_SCALE       16.0f     // 角速度: 1 LSB = 1/16 deg/s
#define BNO055_ACCEL_SCALE      100.0f    // 线性加速度: 1 LSB = 1/100 m/s²
```

### 3.3 数据结构
```c
typedef struct {
    // 四元数 (8字节, 寄存器 0x20-0x27)
    int16_t quat_w_raw, quat_x_raw, quat_y_raw, quat_z_raw;
    float quat_w, quat_x, quat_y, quat_z;

    // 欧拉角 (6字节, 寄存器 0x1A-0x1F)
    int16_t euler_heading_raw, euler_roll_raw, euler_pitch_raw;
    float euler_heading, euler_roll, euler_pitch;  // 单位: 度

    // 线性加速度 (6字节, 寄存器 0x28-0x2D)
    int16_t linear_accel_x_raw, linear_accel_y_raw, linear_accel_z_raw;
    float linear_accel_x, linear_accel_y, linear_accel_z;  // 单位: m/s²

    // 角速度 (6字节, 寄存器 0x14-0x19)
    int16_t gyro_x_raw, gyro_y_raw, gyro_z_raw;
    float gyro_x, gyro_y, gyro_z;  // 单位: deg/s

    // 校准状态 (1字节, 寄存器 0x35)
    uint8_t calib_status;
    uint8_t calib_sys, calib_gyro, calib_accel, calib_mag;

    // 系统状态 (2字节, 寄存器 0x39-0x3A)
    uint8_t system_status, system_error;
} BNO055_Data;
```

### 3.4 初始化流程（IMU 模式）
```c
HAL_StatusTypeDef BNO055_Init(I2C_HandleTypeDef *hi2c, uint8_t reset_on_init)
{
    // 1. 延迟 700ms (芯片上电启动时间)
    HAL_Delay(700);

    // 2. 验证芯片 ID (应为 0xA0)
    if (chip_id != 0xA0) return HAL_ERROR;

    // 3. 切换到 CONFIG 模式
    BNO055_SetMode(hi2c, BNO055_MODE_CONFIG);

    // 4. 可选复位
    if (reset_on_init) { /* 复位逻辑 */ }

    // 5-7. 切换到 Page 1 配置传感器
    BNO055_SetPage(hi2c, 1);
    BNO055_WriteByte(hi2c, 0x08, 0x0D);  // 加速度计: 4g, 62.5Hz
    BNO055_WriteByte(hi2c, 0x0A, 0x38);  // 陀螺仪: 2000dps, 32Hz
    BNO055_WriteByte(hi2c, 0x0B, 0x00);  // 陀螺仪: Normal power

    // 8-11. 切换回 Page 0 配置系统
    BNO055_SetPage(hi2c, 0);
    BNO055_WriteByte(hi2c, 0x3B, 0x00);  // 单位: m/s², deg/s, degrees
    BNO055_WriteByte(hi2c, 0x3E, 0x00);  // 电源: Normal mode

    // 11. 设置为 IMU 模式 (0x08)
    BNO055_SetMode(hi2c, BNO055_MODE_IMU);

    HAL_Delay(20);  // 等待模式切换完成
    return HAL_OK;
}
```

### 3.5 核心功能函数
| 函数名 | 功能描述 | 寄存器范围 |
|-------|---------|----------|
| `BNO055_Init()` | 初始化传感器为 IMU 模式 | 多个 |
| `BNO055_ReadQuaternion()` | 读取四元数 (W, X, Y, Z) | 0x20-0x27 |
| `BNO055_ReadEuler()` | 读取欧拉角 (Heading, Roll, Pitch) | 0x1A-0x1F |
| `BNO055_ReadLinearAccel()` | 读取线性加速度 (去重力) | 0x28-0x2D |
| `BNO055_ReadGyro()` | 读取角速度 | 0x14-0x19 |
| `BNO055_ReadCalibStatus()` | 读取校准状态 | 0x35 |
| `BNO055_ReadAll()` | 一次读取所有数据 | 多个 |
| `BNO055_Test()` | 完整测试程序（UART输出） | 所有 |

## 6. IMU 模式特性分析

### 6.1 优势 ✅
1. **快速校准**: 静止 1-2 秒即可完成陀螺仪校准
2. **稳定姿态**: Roll 和 Pitch 基于重力参考，长期稳定
3. **无磁场干扰**: 不使用磁力计，适合室内和电机附近使用
4. **低功耗**: 仅启用两个传感器

### 6.2 限制 ⚠️
1. **Yaw 漂移**: 无磁力计校正，Heading 会以 1-5°/分钟 的速度漂移
2. **相对方位**: 航向角是相对于启动时刻的方向，不是绝对北向
3. **累积误差**: 长时间运行会产生累积误差

### 6.3 应对策略 📋
1. **AI 视觉融合**: 使用视觉 SLAM 定期校正 Yaw 漂移
2. **定期重置**: 在已知位置重新初始化方向基准
3. **短期导航**: 适合短时间（< 5 分钟）高精度姿态估计
4. **传感器融合**: 配合轮式编码器和视觉里程计

## 8. 已知问题与解决方案

### 8.1 加速度计未校准（Accel: 0）
**问题描述**: 由于传感器安装在车辆上，无法进行 6 面旋转校准。

**影响评估**:
- ✅ Roll/Pitch: 影响极小（基于重力矢量，±0.5° 误差内）
- ✅ Yaw: 无影响（依赖陀螺仪）
- ✅ 陀螺仪: 无影响（已完全校准）
- ⚠️ 线性加速度: 中等影响（可能存在 ±0.1-0.2 m/s² 偏移，但动态响应正常）

**解决方案**:
- 使用传感器主要用于姿态估计（Roll, Pitch, Yaw）
- 速度和位置估计依赖轮式编码器和视觉里程计
- 线性加速度仅用于动态检测（碰撞、急停等）

### 8.2 UTF-8 字符显示问题
**问题描述**: 串口终端不支持 UTF-8 字符（° 和 ²）。

**解决方案**: 已替换为 ASCII 字符（deg 和 ^2）。

### 8.3 Yaw 漂移
**问题描述**: IMU 模式下 Heading 会随时间漂移。

**解决方案**:
- 短期导航（< 5 分钟）: 漂移影响有限（< 5°）
- 长期导航: 结合 AI 视觉 SLAM 进行周期性校正
- 静态基准: 在已知位置重新校准方向

### 11.4 IMU 模式 vs NDOF 模式对比
| 特性 | IMU 模式 (0x08) | NDOF 模式 (0x0C) |
|-----|----------------|-----------------|
| 使用传感器 | 加速度计 + 陀螺仪 | 加速度计 + 陀螺仪 + 磁力计 |
| 校准时间 | 1-2 秒 | 5-30 秒 |
| 磁场干扰 | 无影响 | 受室内磁场影响大 |
| Yaw 稳定性 | 漂移（1-5°/min） | 磁力计校正，长期稳定 |
| Roll/Pitch 稳定性 | 高（重力参考） | 高（重力参考） |
| 适用环境 | 室内、电机附近 | 室外、磁场干净环境 |
| 功耗 | 较低 | 较高 |
